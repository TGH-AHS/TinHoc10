## 📌 GIỚI THIỆU TỔNG QUAN
Kho tài nguyên số hóa và học liệu điện tử môn **Tin học Khối 10**, tập trung vào phân hệ trọng tâm: **Chủ đề 4 — Ứng dụng tin học: Nhập môn lập trình Python (Bài 16 – 17 – 18)**.

Các tài nguyên được thiết kế theo chuẩn:
* Giao diện mô phỏng **VS Code Dark Theme** dành riêng cho học sinh tự gõ lệnh trên IDE trực tuyến `pythononline.net`.
* Hệ thống bảo mật **Anti-Copy & Anti-Inspect** chống gian lận, rèn luyện tư duy tự lập trình.
* Bộ câu hỏi trắc nghiệm trực tác có chấm điểm tức thì và hỗ trợ **Xuất phiếu bài làm PDF chuẩn A4**.
* Ngân hàng câu hỏi định dạng chuẩn **Aiken Text** sẵn sàng import vào các hệ thống LMS (Canvas, Moodle, Cohota).
* Hồ sơ sư phạm: Kế hoạch bài dạy (KHBD theo Công văn 5512/BGDĐT) và Phiếu học tập (PHT) tích hợp Năng lực số (Thông tư 02/2025/TT-BGDĐT).

## 🚀 HƯỚNG DẪN TRIỂN KHAI VÀ SỬ DỤNG
1. **Dành cho Giáo viên:**
   * Sử dụng các tệp `.docx` trong `01_Ke_hoach_bai_day_KHBD` làm hồ sơ giáo án chính khóa.

   * Mở file `Noi_dung_thuc_hanh_LMS_Bai_18.html` trên trình duyệt máy tính hoặc điện thoại.
   * Thực hành gõ code trên Tab 1, chuyển qua Tab 2 làm bài trắc nghiệm và bấm **Xuất file PDF bài làm** để nộp cho giáo viên.
